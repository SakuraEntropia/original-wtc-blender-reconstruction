# 2026-10-15 修正与验收清单

用户已授权修正并直接推送。范围限现有模块，沿用可重复迁移/独立资产结构。

1. 视口：隐藏默认仅供剖看的旧钢构/井壁/机电类型；剖看镜头临时恢复并还原状态。
2. 大堂：退役无图纸依据的镂空环台/画廊与中间楼板；公共大厅改连续Plaza标高铺地，保留地下Concourse研究层。
3. 三叉柱：原轮廓内加入沿主干和三分支的折面脊线；合成单个闭合网格，避免附加圆杆。脊高35mm属视觉估计。
4. 塔冠：曲线饰条由7in改2½in，平直厚度由25mm改6mm，保留二维并集上下连通。按追加意见，上下开合曲线竖向长度各延长至原1.6倍，压缩直线中段，固定原107层座与帽檐上下边界；源文献6ft2in/7ft2in读数单独保留，不把本轮视觉调整称实测。宽/厚为本轮CG参数，不覆盖NIST柱罩宽/高度事实。
5. 南塔屋顶：用环形观景步道、下凹维修区、中央历史停机平台、双出入口、栏杆/围栏、桁架碟形天线替换整块空白高台。布局按照片拟合，未标注制造尺寸不称测量结果。
6. 渲染：全部审查相机Perspective，保持原目标附近画幅；Cycles GPU，Metal只启用真实GPU设备。记录设备和实际渲染日志。

参考：[纪念馆观景台](https://www.911memorial.org/learn/resources/digital-exhibitions/world-trade-center-history/snapshots-work-life)；[1977 AIA Heliport Directory原页及历史航照镜像](https://www.airfields-freeman.com/NY/Airfields_NY_NY_Brooklyn.htm)。镜像文字转录55ft×50ft未见原页尺寸标注，未采用；中央平台按航照比例估8.4m×7.6m；场景绝对标高及步道宽高仍估计。原照片/扫描只在项目外临时查看，不发布。

验收：重开文件，检查两种可见性、连续大堂地面、三叉脊线、薄板实际深度/连通性、南塔分件与网格闭合；透视相机及Cycles GPU配置；实渲重点近景并审图。技术门槛与历史测绘精度分开。
