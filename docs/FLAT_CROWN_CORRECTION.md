# 扁平连通塔冠及穿模修正

## 实测根因

保存文件诊断发现：两塔旧`top_lower_glass`/`top_upper_glass`只隐藏渲染，仍在视口显示；内层机电背墙高出当前维修屋面底1.26999m。旧曲线饰条比直柱饰面前脸外突38mm，侧面普遍启用平滑法线，呈圆润杆状。旧检查未验上下连接，也未验视口旧玻璃。

## 实际修复

`crown_flat_revision.py`由`latest_revision.py`在保存场景迁移及clean build共同调用。

- 旧顶部玻璃同时隐藏视口和渲染；旧冠部集合退出可见场景。
- 机电背墙截止当前维修屋面底以下8mm；不再贯穿屋面板。
- 两跨饰面由3条柱带与4条曲线区域做二维几何并集，再统一挤出。四支曲线与中柱、边柱成为一个闭合连通网格，移除独立曲线和柱罩的叠面/错层。
- 每面29个两跨单元复用网格，外侧补半柱；上下到107层罩面与fascia，前脸共面。钢柱资产仍是独立分段构件。
- 全部正面保持平面，截面为25mm扁平挤出，禁用圆滑法线及倒角。7in曲线视觉宽保留。

源宽度/高度仍来自NIST1-5Av1 Fig4-8及原A·AB·321/323；25mm厚、曲率、绝对标高属于CG估计，不能当制造尺寸。未导入第三方资产。

## 复核

新增`crown_unit`近景。`verify_flat_crown.py`检查：单元只有一个拓扑连通分量、闭合正体积、实际扁平深度、上下座标、旧玻璃视口/渲染状态、背墙净距；对107层活动玻璃与饰面做实际三角网格相交检查。验证保存文件，而非仅查对象数量。
