# 塔冠转角与帽檐补正

2026-10-14追加。沿用[NIST1-5Av1 Fig4-8](https://nvlpubs.nist.gov/nistpubs/Legacy/NCSTAR/ncstar1-5av1.pdf)与[Rose/Fausty1981屋顶原照](https://www.brianrose.com/blog/2015/10/new-yorkthe-walk/)的形态依据。

旧帽檐外轮廓未采用立面罩面外移后的倒角修正，内缘又低于当前CG屋面膜层。现外、内、收口全部采用同一207ft2in结构参考及208ft10in外皮的平行偏移八边形；四角在平面保持45°。斜面板法向6mm厚度、内缘水平包边、外缘下滴口独立分件，转角按一致顶点斜接。表面仍有独立板缝。内缘至屋面+0.60m及1.8m收进量为CG估计，不是女儿墙施工图尺寸。

曲线开合高度保留NIST原值。旧2.5in饰条过细，改为7in宽、75mm深的曲面条，按相邻7in窄罩与照片关系拟合；**宽深都是本轮视觉参数，不能称为原梁截面**。所有曲线继续标structural=False。

增加独立帽檐支承类型集合：真实I形截面斜撑/边梁、短膝撑、跨间支撑、端板与四个六角螺栓头；四个45°转角随八边形布置。0.12×0.18m等截面、板厚、螺栓位置及数量均为CG类型参数；未取得原连接详图。`detail_cap_structure.png`隐藏面板后可检查这些部件。

普通幕墙与三分角罩交界增加独立分段折边框：160mm宽、65mm凸出、退距按11.5in玻璃面衔接。该特殊交界截面缺制造图，参数标为估算；不冒称NIST普通1in窗框的专图。

远距离掠视普通深窗会出现很窄的开口。已做保持几何不变的裁剪范围/无阴影诊断，两者没有消除现象；保存场景可见构件库存未发现额外旧幕墙。检查镜头改为更正面的角度，可辨窗框与回进侧壁。诊断图仅临时缓存，不作历史参考资产发布。
