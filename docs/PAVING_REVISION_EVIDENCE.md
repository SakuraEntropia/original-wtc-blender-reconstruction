# 铺装边界纠错

[LOC 2021636621原照](https://www.loc.gov/item/2021636621/)可见喷泉周边放射铺装与圆形花盆。模型布局继续属于照片解释：1.5m方砖网格、18.05m环外径基准半径、24个花盆的位置、18mm缝宽均未由原始施工图标定。

旧代码仅按方砖中心距离删砖，留下锯齿状缺口；现将方砖平面沿192边喷泉外轮廓、24边花盆轮廓裁切，放射砖与方砖使用同一标高/边界。每砖仍为独立对象、独立mesh。裁切分区共享顶底节点，消除T接点与内部重复侧壁；支持底座沿相同多边形收边。

纯几何探针检查内部圆孔、边缘切口、完全切除三类面积守恒，以及闭合曲面边连接。实际Blender探针：140个裁切砖网格均闭合、正体积；`detail_plaza.png`已重渲染观察，旧大块锯齿缝已消失。近景和完整重开验收见最终reports。

不随包复制档案照片；铺装与材质由本项目代码生成。
