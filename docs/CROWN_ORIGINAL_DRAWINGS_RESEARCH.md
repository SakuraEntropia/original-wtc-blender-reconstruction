## 冠顶斜切与标高

321 冠部立面、323H、302 总立面一致：FIN.110TH FL. 至 parapet 顶 **6′-0″=1.8288 m**；其上铝屋面板再升 **9′-0″=2.7432 m**；至 TOP OF ROOF PANEL 共 **15′-0″=4.5720 m**。321 的转角顶边在立面中明显斜切；仅在俯视做八角形不能满足这个形状。

323D 的 **5′-0″ FROM FIN.110TH FL.** 尺寸止于下方支承/混凝土顶面；其上还有 **2″、9½″、½″** 分层，合计另 1′。它不是一个与 6′ 冲突的冠顶标高。

剖面可确认铝屋面板向上、向内退。设 finished110 为 z=0，parapet 外皮径向位置 x=0，则主要斜板两端为 **(0,1.8288)** 和 **(-R,4.5720)** 米；**R 尚无明确核实数值**。图中存在断线，不应按截图整段长度比例硬推 R。323H 引用 320A；检索表的 133_0.png 实为 AB317，不能代替 AB320。

**1362 ft 与 finished110/冠顶之间的绝对对应尚未核实。** 若保留当前总塔高作为冠顶锚，panelTop=anchor、parapetTop=anchor−2.7432 m、finished110=anchor−4.5720 m 是一种明确的模型映射假设。不能把总高度自动当 finished110 再加 15′。302 的手写高度笔记不作正式尺寸依据。

## 框件、转角平面与收口

- 323A 的正面成对铝 returns、中轴两侧各 **2½″**，总宽 **5″=0.127 m**；外突 **7″=0.1778 m**。它们有分别标注的抛光不锈钢前表面和中缝，适合以 u=±0.0635 m 表达，不能用任意 160 mm 通用 U 形条代替。
- 321E/F 明确分别画出金属屋面板支承框、铝屋面板、transfer track、window washer track 和前述抛光面。支架、轨道、外皮应具有各自的截面和位置。
- 321E/F 转角斜向总长 **7′-2¼″=2.19075 m**，分为 **1′-11⅛″ + 3′-4″ + 1′-11⅛″**；45° 段中间有一个 3′-4″ 模块。角柱参考线至第一条普通立面柱参考线标 **6′-11″=2.1082 m**。斜板不与柱包铝板最外缘齐平。
- 323E 的 facia 顶端回折 **3½″=0.0889 m**；323D 局部支承标 **¼″** 折弯钢板与加劲件、**11⅝″±** 从混凝土外侧到铝面板外皮、**6″** 混凝土 parapet 宽。这些尺寸分别属于翻边、支承和 parapet，不能作为整条斜冠内退 R。
- 323J 给出冠部曲线铝肋的格网构形，说明上部曲线反向；323A 标注 CURVED AL. RIB。曲线肋是转角面板节点的一部分，不能用直线平面斜切替代。
- AA176 确认压顶平面在角部通过对角收口连接两面；其低清局部不提供支架截面或冠顶 R。

## 补核：曲线终点、三维斜接及水平 run

1. **fascia 底没有独立明标的绝对标高。** 321 放大立面比例读数约为 FIN110+4.1′，不能称明标尺寸。可作另一路交叉推断：323J 曲线竖向两段明标 1′7″+7′3″=8′10″；H 的上曲线下方节点明标 FIN110−4′8″；若按 321 图线把该节点对应到反向上曲线的起点，则 fascia 底为 −4′8″+8′10″=**FIN110+4′2″**。尺寸本身明确，节点对应由图面解释，故结论仍是推断。

2. **三维角部可采用下缘截角、上缘收尖的三角角板解释。** 321F 的外侧 45° 斜边为 7′2¼″，两条直角腿标 5′1″；内侧两条正交边交于尖点，未画与外侧平行的内侧 45° 边。321 立面也显示角板/直面交界从 +6′ 斜升至 +15′。可建模为下部截角八边轮廓，上部角点 (h−L,h−L)，L=(7′2¼″)/√2≈5′1″；角板为三角面，两侧屋面分别沿其斜边收口。保持现有正面角板三分接缝，但各分块到顶向同一角点收敛。

3. **L 仍是图面几何推断，不是竣工 run 明尺寸。** 5′1″直接标注的是角部平面腿长；321F 内侧交汇线同时属于 girt/support-frame 图示，没有单独标“panel top apex”。因此上述收尖解释未见明确反证，但不能声称它已独立证明外皮全高 R。侧面普通斜板 run 可暂取 L，45°角板的法向 run 在该解释中为 L/√2；应保留为重建参数与假设，不能把二者混用。
